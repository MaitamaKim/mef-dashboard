# 사진 넣는 법

이 폴더에 아래 이름으로 사진을 넣으면 웹페이지에 자동으로 표시됩니다.
파일이 없으면 "사진 자리" 안내 박스가 대신 보입니다.

| 파일명 | 위치 | 권장 사이즈 |
|---|---|---|
| `hero.jpg` | 최상단 배경 (반투명 처리됨) | 가로 2000px 이상, 가로형 |
| `launching.jpg` | 사업 개요 섹션 — 착수보고회 | 16:9, 가로 1600px |
| `handover.jpg` | 연표 섹션 — 국가고시 문항 입고식 | 16:9, 가로 1600px |

주의: 공개 웹페이지이므로 인물 사진은 초상권 확인 후 사용하십시오.
